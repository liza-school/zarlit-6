# Зарубіжна література, 6 клас — інтерактивний конспект

Частина перша «Біблія — духовна скарбниця людства» (стор. 12–41) за підручником Є. Волощук
та О. Слободянюк «Зарубіжна література. 6 клас» (Київ: Генеза, 2023).
Кожен твір — окремий урок: план сюжету, герої, цитати, терміни, картини з підручника, у кінці —
питання з автоперевіркою. До кожного уроку — шість врізок: **Черкащина**, **Україна**, **Гоґвортс**,
**коні**, **з життя**, **з гри**. Мова спрощена під 11 років, точне формулювання підручника лишається
в таблиці термінів дрібним курсивом. Правила — у `.claude/skills/zarlit6-materials/SKILL.md`.

## Запуск

Подвійний клац по `index.html` — і все. Сервер не потрібен.
Прогрес зберігається в браузері (`localStorage`), кнопка скидання — внизу головної сторінки.

Червоний блок «увага» — місця, де підручник помиляється: чий дім спалили філістимляни (урок 5),

до легенди про Самсона, кадри мультфільму до притчі про сіяча.

## Будова

```
course/
  index.html             каркас сторінки та підключення скриптів
  css/app.css            оформлення, світла й темна теми (спільне з «Географією» й «Природою»)
  img/                   малюнки з PDF підручника
  js/engine.js           маршрути, відмалювання блоків, прогрес у localStorage
  js/lessons/b01..b08.js зміст уроків = дані, без верстки
  js/lessons/test*.js    підсумкові тести: test1 — розділ 1, test2 — розділ 2
  tools/check.js         наскрізна перевірка в headless Chrome
  tools/coverage.json    обов'язковий зміст кожного уроку (перевіряється автоматично)
  tools/errata.json      реєстр знайдених помилок підручника (теж перевіряється)
```

Перевірка перед тим, як віддавати дитині:

```bash
node tools/check.js
```

## Як додати урок

Створити `js/lessons/bNN.js`, підключити його в `index.html`, дописати id у `LESSONS`
в `tools/check.js` і обовʼязковий зміст у `tools/coverage.json`. Урок — список блоків.

Відмінності від «Географії» та «Природи»: параграфів у підручнику немає, тому урок має
`label` («Урок 3») замість `num`, а `group` (назва розділу) і `groupSub` групують картки на головній.

| Тип блока | Для чого | Поля |
|-----------|----------|------|
| `text` | конспект, план сюжету, пояснення | `html` |
| `note` | жовта врізка «важливо»: цитати, риси героя | `html`, `title` |
| `cherkasy` | врізка про Черкащину | `html`, `title` |
| `ukraine` | врізка про Україну | `html`, `title` |
| `life` | приклади з життя, які можна перевірити самому | `html`, `title` |
| `game` | те саме поняття мовою ігор (Brawl Stars, Minecraft) | `html`, `title` |
| `potter` | те саме мовою Гаррі Поттера, і чим справжній світ відрізняється | `html`, `title` |
| `horse` | те саме на конях | `html`, `title` |
| `errata` | помилка підручника | `book` (цитата), `truth` (як насправді), `say` (що казати на уроці) |
| `image` | малюнок з підручника | `src` (файл у `img/`), `caption`, `alt`, `max` (найбільша ширина в px) |
| `gallery` | кілька малюнків поруч | `items: [{src, caption}]`, `cols` (2 або 3) |
| `terms` | таблиця термінів | `items: [{t, d, book}]` — `d` просте пояснення з прикладом, `book` формулювання підручника |
| `summary` | головна думка уроку | `html`, `title` |
| `fold` | згортка | `title`, `html` |
| `quiz` | одна правильна відповідь | `question`, `options`, `answer`, `explain`, `wrong` |
| `multi` | кілька правильних відповідей | `question`, `options`, `answers: [індекси]`, `explain` |
| `order` | поставити по порядку | `question`, `items` (у правильному порядку), `explain` |
| `input` | вписати слово чи число | `question`, `accept: [варіанти]`, `hint`, `placeholder`, `explain` |

Урок може мати `pages` (сторінки підручника в шапці) і `goals` (список «що треба знати»).
Блоки `quiz`, `multi`, `order` та `input` рахуються в прогресі, тому їм потрібен свій `id`.
Відповідь у полі `input` порівнюється м’яко: регістр, апостроф, зайві пробіли й крапка в кінці не впливають.
