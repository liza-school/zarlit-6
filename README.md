# Зарубіжна література, 6 клас

Інтерактивний конспект для Лізи за підручником Є. Волощук та О. Слободянюк «Зарубіжна література»
(Київ: Генеза, 2023). Частина перша «Біблія — духовна скарбниця людства»: вісім уроків (кожен твір
окремо) і підсумковий тест після кожного розділу. Разом 88 завдань з автоперевіркою.

Локально — подвійний клік по `index.html`. Ні сервера, ні збірки, ні інтернету.

* [course/README.md](course/README.md) — що всередині, типи блоків, як додати урок
* [.claude/skills/zarlit6-materials/SKILL.md](.claude/skills/zarlit6-materials/SKILL.md) — правила,
  за якими робиться матеріал

Зроблено за зразком «Географії 6 клас» і «Пізнаємо природу 6 клас»: той самий рушій, ті самі блоки.
PDF підручника в репозиторій не входить — лежить локально поруч із цією текою.

Перевірка перед тим, як віддавати: `cd course && node tools/check.js`
